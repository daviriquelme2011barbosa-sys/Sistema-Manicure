- Existe falta de contraste?
- Existe excesso de contraste?
- Existe ritmo visual?

Verifique se existe excesso de azul. Verifique se a identidade pode ficar mais neutra. O sistema deve funcionar para clínicas, salões, barbearias, manicures, médicos, consultórios e pequenas empresas. Sem parecer feito para um nicho específico.

### Sidebar
Analise largura, espaçamento, peso dos ícones, peso dos textos, área clicável, hover, item ativo, animações, agrupamento, separadores, plano, contraste, profundidade, ícones, padding, border radius, blur, glow.

### Header
Analise busca, avatar, notificações, breadcrumb, espaçamento, altura, peso visual, sombras, separação do conteúdo.

### Dashboard
Analise KPIs, cards, gráficos, espaçamento, hierarquia, peso visual, respiro, organização, narrativa, distribuição. Hoje o Dashboard parece vivo ou apenas vários cards? Como transformá-lo em um Dashboard Premium?

### Cards
Analise altura, padding, radius, sombras, bordas, contraste, espaçamento, hover, microanimações, gradientes, glow, elevação, iluminação, profundidade. Os cards parecem caixas ou componentes premium?

### Tipografia
Analise títulos, subtítulos, descrição, labels, placeholders, KPIs, valores, badges, peso, escala, altura, espaçamento, hierarquia.

### Espaçamento
Verifique padding, margin, grid, colunas, linhas, alinhamentos, respiro, consistência. Tudo deve seguir um sistema baseado em múltiplos de 8.

### Ícones
Analise tamanho, peso, espessura, containers, background, glow, radius, cor, hover, estado ativo.

### Botões
Analise primary, secondary, ghost, danger, outline, hover, focus, loading, disabled, shadow, glow, motion, padding, radius.

### Inputs
Analise altura, radius, border, hover, focus, erro, sucesso, placeholder, ícones, espaçamento.

### Tabelas
Analise cabeçalho, linhas, hover, espaçamento, ordenação, filtros, paginação, leitura, contraste.

### Status
Os status NÃO devem mudar. Continuar obrigatoriamente verde, amarelo e vermelho. Eles possuem prioridade máxima. Nunca utilizar a cor do módulo para substituir status.

### Motion Design
Analise hover, page transition, cards, sidebar, dropdown, modal, toast, tooltip, loading, skeleton, charts, calendário, dashboard, microinterações. Informe duração, easing e intensidade. Nada deve parecer exagerado. Tudo deve parecer premium.

### Dark Theme
Quero um Dark Theme semelhante a Linear, Raycast, GitHub Dark, Vercel e Discord. Não quero um fundo totalmente preto. Quero várias camadas de profundidade. Explique exatamente quais tons utilizar para background, sidebar, topbar, cards, inputs, hover, modal, dropdown, surface, overlay, border, divider, shadow e glow.

### UX
Analise facilidade de navegação, quantidade de cliques, fluxo, feedback, estados vazios, estados de erro, estados de sucesso, confirmações, cancelamentos, modais, drawers, bottom sheets, mobile e desktop.
